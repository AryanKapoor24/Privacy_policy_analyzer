Demo Website

Hosted on Amazon S3 using AWS Free Tier

Welcome!

This is a simple static website hosted entirely on Amazon S3. It demonstrates how cloud storage can serve as a lightweight, scalable, and cost-free hosting solution for static websites using the AWS Free Tier.

Features

  • 🌐 Accessible globally via the AWS S3 website endpoint
  • ⚡ Fast, reliable, and easy to deploy
  • 💰 Hosted fully under AWS Free Tier — zero cost
  • 🧱 Built using only HTML & CSS — no backend required
  • 🔒 Secure access management using AWS IAM policies
